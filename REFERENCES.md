# References

What this agent builds on and borrows from. Each entry says what we take from it.

## What it measures and runs

- [robot_sdk](https://github.com/zacharyyamaoka/robot_sdk): the directory itself; `tools/sdk_graph` (the generator
  and the declaration lint, `robot-sdk-graph/1` in `docs/graph-schema.md`), the page builders, and the gh-pages site.
- Each package's own `robot-sdk.toml` (the decentralized self-description the directory aggregates).
- GitHub's public REST API: [commits](https://docs.github.com/en/rest/commits/commits),
  [compare](https://docs.github.com/en/rest/commits/commits#compare-two-commits),
  [repository activity](https://docs.github.com/en/rest/repos/repos#list-repository-activities) (push times),
  [workflow runs](https://docs.github.com/en/rest/actions/workflow-runs),
  [repository_dispatch](https://docs.github.com/en/rest/repos/repos#create-a-repository-dispatch-event).
- [PyPI JSON API](https://docs.pypi.org/api/json/): the released version of each package.

## The repo format

- [trajectory_tracking_agent](https://github.com/zacharyyamaoka/trajectory_tracking_agent): the reference black-box
  agent (objectives with gates, a frozen ruler, a scored population, a ledger, `ai-team-status/1`).
- [karpathy/autoresearch](https://github.com/karpathy/autoresearch/blob/master/program.md): a frozen scorer, a
  results table per run.
- [MLE-bench](https://github.com/openai/mle-bench): description, grader and checksums as the scorer's shape.

## Prior art for keeping a directory fresh

- [Dependabot](https://docs.github.com/en/code-security/dependabot) / [Renovate](https://docs.renovatebot.com/):
  scheduled sweeps that open PRs when an upstream moves (ideas: discovery sweep, release-lag PRs).
- [awesome-lint](https://github.com/sindresorhus/awesome-lint) and curated "awesome" lists' link checkers
  ([lychee](https://github.com/lycheeverse/lychee)): dead links as a CI gate.
- [ROS index](https://index.ros.org/) and [rosdistro](https://github.com/ros/rosdistro): a central index built from
  per-repo metadata (package.xml), regenerated by a bot.
